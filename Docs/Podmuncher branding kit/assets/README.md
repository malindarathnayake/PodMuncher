Wordmarks are live text in Bricolage Grotesque ExtraBold 800. Convert to outlines before handing to anyone without the font.

## png/
Transparent exports of every SVG at the sizes in the filename (symbol 512/256/64, favicon 48/32/16, app icon 1024/512/180, lockups @2x, mascot 1200 wide). readme-banner and social-preview are opaque by design. Banner and social PNGs embed only Bricolage Grotesque; secondary lines render in a fallback sans/mono — re-export from the SVG with all fonts installed for final use.
